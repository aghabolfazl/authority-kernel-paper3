# Security Policy

This is a research prototype and is not intended for safety-critical deployment.

## Reporting
Do not disclose sensitive exploit details publicly before coordinating a responsible fix. For this research scaffold, contact the maintainer through the contact channel listed on the eventual public repository. No public repository URL or security contact is asserted here because one has not been supplied.

## Deployment warning
Never use this prototype to command a real vehicle, robot, or other safety-critical system. A passing test suite does not establish functional safety, cybersecurity certification, or real-world safety.
